# Case Studies

## Case Study 1 — AI Voice Agent for Logistics Company

A mid-sized logistics company was missing 40% of after-hours calls, losing potential revenue.

**Challenge:** High volume of after-hours calls going unanswered, leading to missed leads and revenue loss.

**Solution:** We deployed an AI voice agent handling FAQs, shipment tracking, and callback scheduling, integrated with their existing CRM.

**Results:**
- 90% of after-hours calls handled automatically
- 25% increase in lead conversion
- EUR 50K annual savings in missed calls

**Tech:** LLM, Twilio, CRM API, Python

**Timeline:** 6 weeks

## Case Study 2 — FileMaker ERP for Manufacturing

A manufacturer was running on spreadsheets and paper, causing inventory errors and delays.

**Challenge:** Manual processes causing inventory inaccuracies and order processing delays.

**Solution:** We built a custom FileMaker ERP with inventory management, purchase orders, production tracking, and financial reporting.

**Results:**
- Inventory accuracy improved from 70% to 99%
- Order processing time reduced by 60%
- ROI within 6 months

**Tech:** Claris FileMaker, FileMaker Server, API Integrations

**Timeline:** 14 weeks

## Case Study 3 — Legacy FileMaker Modernization

A distributor was running on FileMaker 11, unable to access data on mobile or support remote work.

**Challenge:** Outdated FileMaker version limiting mobility and remote access capabilities.

**Solution:** We migrated to the latest FileMaker, deployed WebDirect for browser access, and built a companion mobile app.

**Results:**
- Full remote access enabled
- 30% faster order processing
- Eliminated desktop dependency
- Zero data migration issues

**Tech:** FileMaker 21, FileMaker WebDirect, FileMaker Go

**Timeline:** 8 weeks

## Case Study 4 — Multi-System API Integration

An e-commerce company was manually entering data between Shopify, Exact Online, and DHL, losing 15 hours per week.

**Challenge:** Manual data entry between multiple systems causing errors and time waste.

**Solution:** We built an automated API pipeline: Shopify orders sync to Exact Online accounting, and shipping labels generate via DHL API.

**Results:**
- 15 hours per week saved
- Zero manual entry errors
- Order-to-ship time reduced from 4 hours to 15 minutes

**Tech:** Shopify API, Exact Online API, DHL API, Node.js

**Timeline:** 5 weeks

## Case Study 5 — Custom Web Portal for Field Service

A field service company had no centralized way to manage technicians, schedules, and customer requests.

**Challenge:** Disconnected scheduling and communication causing inefficiency.

**Solution:** We built a web portal with technician scheduling, job assignment, real-time status updates, and customer self-service.

**Results:**
- 30% more jobs completed per day
- Customer satisfaction up 40%
- Dispatcher workload reduced by 50%

**Tech:** React, Node.js, PostgreSQL, AWS

**Timeline:** 16 weeks
